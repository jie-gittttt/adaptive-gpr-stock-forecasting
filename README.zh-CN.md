# 自适应高斯过程回归股票预测

[English](README.md) | [中文](README.zh-CN.md)

**研究问题 · 模型对比 · 可复现实验**

高斯过程回归假设它的核函数在整条训练序列上平稳。股价不是。本项目测量这个假设在市场性质
发生变化时的代价，并检验一个波动率感知的自适应窗口能否把大部分损失挽回来。

---

## 1. 问题

高斯过程回归是一种贝叶斯非参数回归：它在函数空间上放置先验，再用观测数据去条件化。
这个先验编码在核函数里，而核函数的超参数是**拟合一次之后就固定不变**的。

这就是一个平稳性假设。它的含义是：两个观测之间的协方差只取决于它们在时间上相距多远，
而与它们**发生在什么时候**无关。真实的价格序列违背这一点。宏观平稳期与结构性转折期
服从不同的统计规律，在其中一个上拟合出的核函数，会把错误的先验带到另一个上去。

失败模式很具体，也可以测量。用 2021 年牛市拟合核函数，再去预测 2022 年初的崩盘：

- 核函数学到的是「价格向上走」，于是它预测向上。
- 在「预测涨则做多、否则空仓」的策略下，模型在整个下跌过程中始终满仓。
- 它**没有任何机制察觉自己错了**，因为固定的先验里不包含「市场性质已经变了」这件事。

**本项目要回答的问题**：这个代价有多大，以及通过对训练窗口做一个廉价的改动，
能挽回其中多少。

## 2. 方法

### 数据与目标

| | |
| :--- | :--- |
| **来源** | NASDAQ 官网公开历史行情（[nasdaq.com](https://www.nasdaq.com/)），下载为 CSV |
| **区间** | 2015 年 12 月 – 2025 年 12 月，日线 |
| **标的** | GOOGL · MSFT · NVDA · TSLA · NDX（指数） |
| **预测目标** | 次日收盘价，在对数空间建模后再指数还原 |
| **特征** | 由 `code/clean_features.py` 构造；缩放器仅在训练集上拟合 |

### 对比的四种配置

| 配置 | 窗口 | 是否重训 |
| :--- | :--- | :--- |
| **G1 静态** | 全量历史 | 只训一次，之后冻结 |
| **G2 短窗** | 30 日 | 每步重训 |
| **G2 长窗** | 200 日 | 每步重训 |
| **G3 自适应** | 15–200 日，由波动率驱动 | 每步重训 |

四种配置 × 两种市场状态。两个区间的选取原则是：一个大致满足平稳性，另一个明显不满足。
这正是让对比可解释的原因——配置之间的任何差异都可以归因于**所处的市场状态**，而不是实验设定。

- **转折期**——用 2021 年及之前训练，在 2022 年头约 40 个交易日上测试。
- **平稳期**——用之前的历史训练，在 2024 年上测试。

### 自适应窗口

Group 3 按**每一个预测步**、根据已实现波动率选择窗口长度，取值限制在 15 到 200 日之间：

```
   窗口
   长度
    200 ┤────────────┐
        │            │              ┌──────
        │  平稳期：   │   转折期：    │  重新稳定：
        │  保留全部   │   丢弃失效数据 │  窗口长回去
        │  历史       │              │
     15 ┤            └──────────────┘
        └──────────────────────────────────────▶ 时间
             2021 牛市        2022 崩盘
```

理由是这样的：长窗口是一个低方差、高偏差的估计量。当过程平稳时它是对的，
因为每多一个观测都带来信息。而当过程发生变化时，这些同样的观测变得**主动产生误导**——
它们描述的是一个已经不复存在的市场状态。波动率上升是这个转变可观测的特征，
因此窗口随之收缩，等新的水平稳定下来后再重新扩张。

核函数选用 **Rational Quadratic**：它是平方指数核的尺度混合，尾部更重，
因而更有能力表示「在不同时间尺度上结构不同」的情形——结构转折正是这种情形。

### 评价指标

| 指标 | 定义 |
| :--- | :--- |
| **RMSE** / **MAPE** | 价格水平上的标准误差 |
| **DA** | 方向准确率——与次日实际涨跌方向的符号一致率 |
| **Regret** | 相对「上帝视角」多空择时策略所**放弃**的累计收益 |

**关于 Regret 的准确定义**：每一步，模型预测上涨则做多，否则空仓；
上帝视角则在每一个实际上涨的日子都做多。Regret 是两者实际收益之差的累加。
因此它是一个**放弃收益**的度量，不是误差度量；又因为它会累加，
它只在**同一测试窗口内**的配置之间可比。

## 3. 结果

### 转折期——用 2021 训练，在 2022 年初崩盘上测试

约 40 个交易日。四种配置跑在同一窗口上，因此各列之间可比。

| Ticker | G1 静态 RMSE / Regret | G2 短窗(30d) | G2 长窗(200d) | **G3 自适应** |
| :--- | --: | --: | --: | --: |
| GOOGL | 4.30 / 36.05% | 3.40 / 34.55% | 3.19 / 35.53% | 3.29 / **29.70%** |
| TSLA | 20.23 / 78.38% | 13.35 / 61.60% | 13.23 / **57.86%** | 15.24 / 73.50% |
| NDX | 436.14 / 31.71% | 332.43 / 35.17% | 305.27 / **32.65%** | 304.05 / 34.27% |
| MSFT | 8.52 / 30.05% | 6.75 / 36.27% | 6.29 / 31.18% | **6.27** / **24.96%** |
| NVDA | 1.80 / 70.57% | 1.11 / 69.89% | **1.03** / **64.68%** | 1.06 / 66.01% |

**静态基线在哪里失效。** 全面失效。TSLA 放弃了上帝视角收益的 78.38%，NVDA 是 70.57%——
在「涨则做多、否则空仓」的策略下，模型就是一路满仓穿过了整个崩盘。
这正是第 1 节预言的失败模式，量级之大，无需再作论证。

**各方案各自赢在哪里：**

| | 领先之处 |
| :--- | :--- |
| **G3 自适应** | GOOGL（29.70%）与 MSFT（24.96%）的 Regret 最低；MSFT（6.27）与 NDX（304.05）的 RMSE 最低；GOOGL、MSFT、NVDA 三支的 DA 最高 |
| **G2 长窗(200d)** | TSLA 上 RMSE 与 Regret 双项最优——该标上的最佳配置 |
| **G2 短窗(30d)** | 没有一项单独最优，但在 TSLA 上与最高 DA 持平，且是重训配置里最省时的 |

**自适应模型在哪里仍然输。** 在 TSLA 上它两项指标都不及固定 200 日窗口
（Regret 73.50% 对 57.86%）。这个机制是靠丢弃数据换取稳定性的，
而在一个波动率长期偏高的标的上它丢得太多——结果恰恰在最需要长窗口稳定的时刻，
表现得像一个短窗口。同样的效应也让它在 NVDA 上丢掉了 RMSE 的领先。

**窗口不是越短越好。** 从 200 日砍到 30 日大幅降低了误差，但短窗增加方差。
在平稳期序列上，短窗的 Regret 反而高于长窗——这是偏差与方差的取舍，
不是一个标着「历史越少越灵敏」的旋钮。

### 对照组——平稳期（2024）

RMSE。这个窗口比上面的更长，因此上面的 Regret 数值在此**不可比**，故不列出。

| Ticker | G1 静态 | G2 长窗(200d) | G2 短窗(30d) |
| :--- | --: | --: | --: |
| GOOGL | 7.69 | **6.69** | 7.52 |
| TSLA | **16.94** | 19.37 | 22.79 |
| NDX | **414.62** | 474.81 | 494.29 |
| MSFT | **8.65** | 10.82 | 11.40 |
| NVDA | **5.30** | 7.05 | 6.96 |

两点读法，第二点不太舒服：

1. **五支标的中，长窗在四支上胜过短窗**——市场状态稳定时，更多历史确实能把趋势拟合得更准，
   这正是自适应设计想要利用的行为。
2. **但静态基线在四支上胜过两者。** 为了**跟踪**一个本就平稳的市场而主动丢弃历史，
   是自己给自己制造损失。滑动窗口方法只有在市场状态真的发生移动时才值回票价，
   而平稳期恰恰是它不该触发的情形。

### 开销

转折期窗口下，每支标的的秒数：

| 配置 | 窗口 | 耗时 |
| :--- | :--- | --: |
| G1 静态 | 全量历史，只训一次 | **0.27 – 0.30 s** |
| G2 短窗 | 30 日，每步重训 | 2.7 – 3.4 s |
| G2 长窗 | 200 日，每步重训 | 10.6 – 19.1 s |
| **G3 自适应** | 15–200 日，每步重训 | 2.5 – 6.4 s |

诚实的说法不是「自适应模型很快」。而是：**自适应窗口落在重训类配置里便宜的一端**——
在同一个测试窗口上比固定 200 日窗口便宜 2–6 倍，因为它的窗口大部分时间都是压缩的。
真正快一个数量级的选项是**根本不重训**，而那恰恰是精度最差的配置。
自适应窗口的定位是：用长窗口运行成本的一小部分，把静态基线的精度买回来大部分——
而不是去挑战静态基线的运行时间。

### 方向准确率

自适应模型在五支标的中的三支上取得最高 DA（GOOGL、MSFT、NVDA），在另外两支上与最佳持平。
MSFT 达 **56.4%**，对比静态基线的 51.3%。DA 按约 40 日窗口统计，
以 1/39 ≈ 2.6% 为步长跳变——MSFT 这个差距是有意义的，只差一档则谈不上。

## 4. 复现

```bash
pip install -r requirements.txt
# numpy>=1.24, pandas>=2.0, matplotlib>=3.7, scikit-learn>=1.3, scipy>=1.10
```

Python 3.9+。

### 数据

六个 CSV 已包含在 [`data/`](data/) 中——GOOGL、MSFT、NVDA、TSLA 与 NDX 的十年日线
（2015 年 12 月 – 2025 年 12 月），另有一份 MSFT 的 1 年数据。都是公开数据，
一并提交是为了让实验不必联网就能跑起来。

如需自行更新，从
<https://www.nasdaq.com/market-activity/stocks/GOOGL/historical> 下载，
保持文件名格式 `HistoricalData_<TICKER>_10Y.csv` 与原始表头
（`Date,Close/Last,Volume,Open,High,Low`）。解析器依赖 NASDAQ 的**倒序**行序
与带 `$` 前缀的价格字符串。

### 运行

```bash
# 1. 清洗 + 特征工程 → preprocessed_data/（不入版本库）
python code/clean_features.py

# 2. 各组实验 → figures/<组名>/
python code/group1_A.py   # 静态基线 · 平稳期
python code/group1_B.py   # 静态基线 · 转折期
python code/group2_A.py   # 短窗 vs 长窗 · 平稳期
python code/group2_B.py   # 短窗 vs 长窗 · 转折期
python code/group3.py     # 自适应模型

# 3. 报告插图
python code/fig1_nonstationarity.py
python code/fig2_adaptive_window.py
```

必须最先运行 `clean_features.py`，各组脚本读取它的输出。
所有路径相对脚本文件解析，从任意工作目录运行都可以。

### 验证结果

第 3 节的每一个数字都由上述脚本的 stdout 复现。[`results.md`](results.md) 逐组记录了
完整的预期输出——跑一个脚本，把打印出来的汇总表与对应区块对照即可：

```bash
python code/group1_B.py    # 与 results.md 中的 "group1B" 区块对照
```

两点预期差异：

- **耗时会与记录值不同。** 那是生成 `results.md` 时的机器上的墙钟时间，
  是本项目里最不可复现的量。RMSE / DA / Regret 在数据与固定随机种子给定后是确定性的，
  秒数不是。
- **`group3.py` 依赖该文件里实现的自适应规则阈值。** 改动阈值，转折期那张表就会变。

## 已知局限

- **只有一次结构转折、五支标的。** 2022 年崩盘是单一事件，
  五支标的中三支是美国大盘科技股。这里的结论没有说明那些波动率阈值能否迁移到其他行情事件。
- **自适应规则未经调优，也未经样本外验证。** 它在同一个事件上既拟合又评估，
  因此其参数没有被证明最优，也没有用留出的转折事件确认过。
- **转折期没有做概率预测评估。** GPR 的最大优势是预测分布，但这里只对均值计分——
  只有 `baseline.py` 单独做了 95% 区间的覆盖率验证。
  转折期的区间校准，本应是最差、因而信息量最大的部分，没有报告。
- **核函数与窗口是一起换的。** Rational Quadratic 与自适应窗口同时引入，
  因此性能提升无法在两者之间干净地归因。
- **没有交易模拟。** Regret 是一个类收益量，但没有计入交易成本、仓位管理、滑点或资金模型。
  它度量的是选错的代价，不是任何策略的盈利能力。
- **每种配置只做一次训练/测试划分。** 是点估计，没有置信区间，也没有重复采样，
  因此优化器初始化带来的方差未被刻画。

## 与课程仓库的关系

本项目源自 [stochastic-processes](https://github.com/jie-gittttt/stochastic-processes)
的第三次作业，那是一个课程合集，三次作业构成一条脉络：用随机过程的语言描述现象、
严格推导一个模型、再用真实数据检验它。本仓库是这条脉络的第三步独立展开的版本——
把方法、基线与失败分析给到它们真正需要的篇幅。
